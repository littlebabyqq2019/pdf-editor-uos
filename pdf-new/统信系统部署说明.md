# 统信系统Docker部署说明

## 一、在Windows电脑上构建镜像

### 1. 确保Docker Desktop已启动

### 2. 运行构建脚本
```bash
docker-build.bat
```

或手动执行：
```bash
# 构建Linux/AMD64镜像
docker build --platform linux/amd64 -t pdf-editor:latest .

# 导出镜像
docker save -o pdf-editor-image.tar pdf-editor:latest
```

## 二、传输镜像到统信系统

将生成的 `pdf-editor-image.tar` 文件传输到统信系统电脑上。

传输方式可以是：
- U盘拷贝
- 网络传输（scp、ftp等）
- 共享文件夹

## 三、在统信系统上部署

### 1. 加载镜像
```bash
docker load -i pdf-editor-image.tar
```

### 2. 查看镜像
```bash
docker images | grep pdf-editor
```

### 3. 运行容器

#### 方式一：简单运行
```bash
docker run -d \
  --name pdf-editor \
  -p 5000:5000 \
  --restart unless-stopped \
  pdf-editor:latest
```

#### 方式二：带数据持久化（推荐）
```bash
# 创建数据目录
mkdir -p ~/pdf-editor/processed

# 运行容器
docker run -d \
  --name pdf-editor \
  -p 5000:5000 \
  -v ~/pdf-editor/processed:/app/processed \
  -e TZ=Asia/Shanghai \
  --restart unless-stopped \
  pdf-editor:latest
```

### 4. 查看运行状态
```bash
# 查看容器状态
docker ps

# 查看容器日志
docker logs pdf-editor

# 实时查看日志
docker logs -f pdf-editor
```

### 5. 访问应用
打开浏览器访问：
```
http://localhost:5000
```

或从局域网其他设备访问：
```
http://统信系统IP:5000
```

## 四、常用管理命令

### 停止容器
```bash
docker stop pdf-editor
```

### 启动容器
```bash
docker start pdf-editor
```

### 重启容器
```bash
docker restart pdf-editor
```

### 删除容器
```bash
docker rm -f pdf-editor
```

### 删除镜像
```bash
docker rmi pdf-editor:latest
```

### 查看容器资源使用
```bash
docker stats pdf-editor
```

### 进入容器（调试用）
```bash
docker exec -it pdf-editor bash
```

## 五、故障排除

### 1. 容器无法启动
```bash
# 查看详细日志
docker logs pdf-editor

# 检查端口是否被占用
netstat -tunlp | grep 5000
```

### 2. 端口已被占用
修改映射端口：
```bash
docker run -d --name pdf-editor -p 8080:5000 pdf-editor:latest
# 然后访问 http://localhost:8080
```

### 3. 权限问题
```bash
# 确保当前用户在docker组
sudo usermod -aG docker $USER

# 重新登录后生效
```

### 4. 磁盘空间不足
```bash
# 清理无用的镜像和容器
docker system prune -a
```

## 六、性能优化建议

### 1. 限制资源使用
```bash
docker run -d \
  --name pdf-editor \
  -p 5000:5000 \
  --memory="2g" \
  --cpus="2" \
  pdf-editor:latest
```

### 2. 使用Docker Compose（推荐）
如果统信系统支持docker-compose，可以创建 `docker-compose.yml`：

```yaml
version: '3.8'

services:
  pdf-editor:
    image: pdf-editor:latest
    container_name: pdf-editor
    ports:
      - "5000:5000"
    volumes:
      - ./processed:/app/processed
    restart: unless-stopped
    environment:
      - TZ=Asia/Shanghai
    deploy:
      resources:
        limits:
          memory: 2G
          cpus: '2'
```

然后运行：
```bash
docker-compose up -d
```

## 七、备份和恢复

### 备份镜像
```bash
docker save -o pdf-editor-backup.tar pdf-editor:latest
```

### 恢复镜像
```bash
docker load -i pdf-editor-backup.tar
```

## 八、更新部署

### 1. 获取新镜像文件
从Windows电脑获取新的 `pdf-editor-image.tar`

### 2. 停止并删除旧容器
```bash
docker stop pdf-editor
docker rm pdf-editor
```

### 3. 删除旧镜像（可选）
```bash
docker rmi pdf-editor:latest
```

### 4. 加载新镜像
```bash
docker load -i pdf-editor-image.tar
```

### 5. 重新运行容器
```bash
docker run -d --name pdf-editor -p 5000:5000 pdf-editor:latest
```

## 九、注意事项

1. **架构兼容性**：镜像是为 x86_64 (AMD64) 架构构建的，确保统信系统是该架构
2. **防火墙**：如需局域网访问，确保防火墙开放5000端口
3. **数据持久化**：使用 `-v` 参数挂载卷以保存处理后的文件
4. **资源限制**：根据实际需求调整内存和CPU限制
5. **安全性**：生产环境建议配置HTTPS和访问控制

## 十、查看系统架构

在统信系统上确认架构：
```bash
uname -m
# 应该显示 x86_64 或 amd64
```

如果显示 aarch64 或 arm64，需要重新构建ARM架构镜像：
```bash
# 在Windows上重新构建
docker build --platform linux/arm64 -t pdf-editor:latest .
docker save -o pdf-editor-image.tar pdf-editor:latest
```
