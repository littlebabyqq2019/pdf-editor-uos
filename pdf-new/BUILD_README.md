# PDF编辑工具 - 打包说明

版本：1.4

## 快速打包

### 方法一：使用批处理文件（推荐）

1. 双击运行 `build_exe.bat`
2. 等待打包完成（约3-5分钟）
3. 在 `dist` 文件夹中找到 `PDF编辑工具.exe`

### 方法二：手动打包

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 创建图标
python create_icon.py

# 3. 创建版本信息
python create_version_info.py

# 4. 打包
pyinstaller --clean pdf-editor.spec
```

## 打包说明

### 生成的文件

- **dist/PDF编辑工具/** - 程序文件夹（约300-400MB）
  - 文件夹内包含主程序exe和所有依赖文件
  - 无需Python环境，可在任何Windows电脑上运行
  - **启动速度快**（1-2秒即可启动）
  - 运行时显示控制台窗口
  - 需要整个文件夹一起复制

### 配置文件说明

- **pdf-editor.spec** - PyInstaller打包配置
  - 图标：app_icon.ico
  - 版本：1.4
  - 模式：文件夹（onedir）- 启动速度快
  - 控制台：显示（便于查看运行状态）

- **version_info.txt** - Windows版本信息
  - 文件版本：1.4.0.0
  - 产品版本：1.4.0.0
  - 包含中文描述

- **app_icon.ico** - 应用程序图标
  - 来源：1.png
  - 包含多种尺寸：16x16至256x256

## 使用说明

### 运行程序

1. 双击 `PDF编辑工具.exe`
2. 会弹出控制台窗口，显示启动信息
3. 打开浏览器，手动访问 http://localhost:5000
4. 保持控制台窗口运行（关闭窗口会终止服务）

### 功能特性

1. **去红头及公章** - 移除扫描PDF中的红色印章和红头文字
2. **去公章** - 仅移除公章，保留红头
3. **转图片后去红头及公章** - 先转换为扫描型PDF再处理
4. **去背景** - 清除背景杂色、透视矫正、二值化（新优化）
5. **转Word** - PDF转DOCX格式
6. **图片转PDF** - 多张图片合成PDF
7. **删除PDF页面** - 可视化删除和重排页面
8. **合并PDF文件** - 多个PDF合并为一个
9. **拆分PDF文件** - 按页码范围拆分

### 注意事项

1. **首次运行**：可能需要防火墙授权
2. **文件位置**：
   - uploads 文件夹：上传的文件
   - processed 文件夹：处理后的文件
   - startup.log：启动日志（如有问题请查看）

3. **终止程序**：
   - 关闭浏览器标签页不会终止程序
   - 在控制台窗口按 Ctrl+C 停止服务
   - 或直接关闭控制台窗口

4. **重新打包**：如需修改代码后重新打包，请先删除 `build` 和 `dist` 文件夹

## 系统要求

- **操作系统**：Windows 7/8/10/11（64位）
- **内存**：建议4GB以上
- **磁盘空间**：至少500MB
- **网络**：本地运行，无需联网

## 故障排除

### 无法启动

1. 检查是否被杀毒软件拦截
2. 查看 `startup.log` 文件
3. 尝试以管理员身份运行

### 端口占用

如果5000端口被占用，程序无法启动，需要：
1. 找到占用5000端口的程序并关闭
2. 或修改源码中的端口号重新打包

### 如何访问

程序不会自动打开浏览器，请手动打开浏览器访问：http://localhost:5000
