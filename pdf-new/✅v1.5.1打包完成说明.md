## ⚙️ 技术细节

### 修改的核心代码
```python
# pdf_processor.py

# 1. 获取页码
page_num = page.number
is_first_page = (page_num == 0)

# 2. 统一保护区域
upper_area_y_threshold = page_height * 0.63  # 从40%改为63%

# 3. 判定逻辑
if is_first_page and y_center > upper_area_y_threshold:
    in_upper_area = True  # 首页上部，保护
else:
    in_middle_or_bottom = True  # 首页下部或非首页，删除
```
