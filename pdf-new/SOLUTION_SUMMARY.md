# WPS公章显示问题 - 解决方案摘要

## 问题陈述

文本型PDF文件经过"去红头及公章"处理后：
- ✅ Adobe Reader、Foxit Reader等主流PDF阅读器：公章不可见
- ❌ **WPS手机版和WPS电脑版：公章仍然可见**

## 根本原因

```
┌─────────────────────────────────────────────────────────┐
│  旧代码处理流程                                           │
├─────────────────────────────────────────────────────────┤
│  1. 删除页面 /Annots 引用       ✓                        │
│  2. 签名字段对象仍存在          ✗                        │
│  3. 外观流 (/AP) 仍存在         ✗                        │
│  4. WPS 扫描并渲染外观流        ✗ 导致公章可见           │
└─────────────────────────────────────────────────────────┘
```

**关键发现：**
- WPS与其他PDF阅读器的渲染机制不同
- WPS会主动扫描整个PDF文档中的所有签名字段对象
- 即使签名字段未被页面的`/Annots`引用，WPS仍会渲染其`/AP`（外观流）

## 解决方案

### 修改的核心代码

**文件：** `pdf_processor.py`  
**方法：** `_remove_annots_from_page_object()`

```python
# 步骤1：清空外观流对象
ap_xref = 提取/AP/N引用的xref
doc.update_object(ap_xref, "<< /Length 0 >>\nstream\n\nendstream")

# 步骤2：重构签名字段对象，移除关键键
new_obj = """<<
  /T (字段名)
  /F 132
  /Rect [x0 y0 x1 y1]
  /P page_xref
>>"""
doc.update_object(xref, new_obj)

# 步骤3：删除页面的/Annots引用
doc.xref_set_key(page_xref, "Annots", "null")

# 步骤4：垃圾回收
doc.save(output_path, garbage=4, deflate=True, clean=True)
```

### 修复原理

```
┌─────────────────────────────────────────────────────────┐
│  新代码处理流程                                           │
├─────────────────────────────────────────────────────────┤
│  1. 清空外观流对象内容          ✓                        │
│  2. 重构签名字段，移除/AP       ✓                        │
│  3. 删除页面 /Annots 引用       ✓                        │
│  4. 垃圾回收清理                ✓                        │
│  5. WPS 无外观流可渲染          ✓ 公章不可见             │
└─────────────────────────────────────────────────────────┘
```

## 技术细节

### PDF签名字段结构

```
签名字段对象 xref=72
<<
  /FT /Sig                  ← 字段类型：签名
  /Subtype /Widget          ← 表单控件
  /AP <<                    ← 外观流（关键！）
    /N 71 0 R               ← 指向外观对象
  >>
  /Rect [...]               ← 位置坐标
  /V 65 0 R                 ← 签名值
  /DR << ... >>             ← 默认资源
>>

外观流对象 xref=71
<<
  /Type /XObject
  /Subtype /Form
  /Resources << /XObject << /FRM 70 0 R >> >>
  /BBox [0 0 123.06 123.06]
  /Length 29
>>
stream
  ... 公章图像数据 ...
endstream
```

### 为什么WPS不同

| PDF阅读器 | 渲染机制 |
|-----------|---------|
| Adobe Reader<br>Foxit Reader<br>Chrome | 只渲染页面`/Annots`数组中引用的注释 |
| **WPS** | **扫描全文档，渲染所有包含`/AP`的签名字段** |
