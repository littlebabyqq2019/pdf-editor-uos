# 修改说明 - 统一文本型和扫描型PDF的保护区域

## 修改时间
2024年12月8日 16:22

## 修改文件
`pdf-new/pdf_processor.py` 第897行

## 修改内容

### 修改前
```python
# 首页上部区域：y > page_height * 0.4（距底部大于40%）
upper_area_y_threshold = page_height * 0.4
```

### 修改后
```python
# 首页上部区域：y > page_height * 0.63（距底部大于63%），与扫描型PDF保持一致
upper_area_y_threshold = page_height * 0.63
```

## 修改原因

### 1. 统一标准
- **扫描型PDF**：使用63%保护区域（第241-243行）
- **文本型PDF**：之前使用40%保护区域
- **目标**：两种PDF类型使用相同的标准

### 2. 更合理的保护范围
- 40%阈值过于保守，容易误判
- 63%更符合实际红头文字的分布范围
- 红头文字通常占据页面上部较大区域

## 对1.pdf的影响

### 修改前后对比

**页面高度**：841.9 pt

| 项目 | 40%阈值 | 63%阈值 |
|------|---------|---------|
| **阈值坐标** | 336.76 pt | 530.40 pt |
| **第4页公章** | y=628.7 pt | y=628.7 pt |
| **判定结果** | 628.7 > 336.76<br>→ 上部（跳过）❌ | 628.7 > 530.40<br>→ 上部（跳过）❌ |

**注意**：即使改为63%，1.pdf第4页的公章(y=628.7)仍然会被判定为上部区域。

### 但是没关系！

因为我们已经增加了**页码判断**：
- 第4页是**非首页**
- 非首页**不使用保护区域判定**
- 直接 `in_middle_or_bottom = True`
- **结果：公章被删除** ✅

## 判定逻辑对比

### 扫描型PDF（原有逻辑）
```python
if page_num == 0:
    # 首页：保护上部63%区域
    img = self._remove_red_with_header_protection(img, protect_ratio=0.63)
else:
    # 非首页：全页检测
    img = self._remove_all_red_from_image(img, is_first_page=False)
```

### 文本型PDF（修改后逻辑）
```python
# 首页保护区域：63%
upper_area_y_threshold = page_height * 0.63
is_first_page = (page_num == 0)

# 判定逻辑
if is_first_page and y_center > upper_area_y_threshold:
    in_upper_area = True  # 首页上部63%，保护
else:
    in_middle_or_bottom = True  # 首页下部37%或非首页，删除
```
