# PDF编辑工具 - 开机自启配置说明

## ✅ 已自动配置（使用快速部署脚本）

如果您使用了 `统信系统快速部署.sh` 脚本，那么**开机自启已经自动配置好了**！

### 自动配置包括：

1. **Docker服务开机自启**
   - 执行了 `systemctl enable docker`
   - 系统启动时Docker会自动运行

2. **容器自动重启策略**
   - 配置了 `--restart unless-stopped`
   - Docker启动后会自动运行此容器
   - 即使容器意外停止也会自动重启

### 验证配置

运行以下命令验证配置：

```bash
# 检查Docker服务是否设置为开机自启
systemctl is-enabled docker
# 应该显示: enabled

# 检查容器的重启策略
docker inspect --format='{{.HostConfig.RestartPolicy.Name}}' pdf-editor
# 应该显示: unless-stopped
```

## 🔄 重启策略说明

### `--restart unless-stopped` 的行为

| 情况 | 容器是否自动启动 |
|------|------------------|
| 系统重启 | ✅ 自动启动 |
| Docker服务重启 | ✅ 自动启动 |
| 容器崩溃/异常退出 | ✅ 自动重启 |
| 手动停止容器 (`docker stop`) | ❌ 不会自动启动 |
| 系统重启前手动停止过容器 | ❌ 重启后不会启动 |

### 其他重启策略（可选）

如果需要更改重启策略：

```bash
# 1. 停止并删除现有容器
docker stop pdf-editor
docker rm pdf-editor

# 2. 使用新策略重新创建容器

# always - 总是自动重启（即使手动停止过）
docker run -d --name pdf-editor -p 5000:5000 \
  --restart always \
  pdf-editor:latest

# on-failure - 仅在失败时重启
docker run -d --name pdf-editor -p 5000:5000 \
  --restart on-failure:5 \
  pdf-editor:latest

# no - 不自动重启
docker run -d --name pdf-editor -p 5000:5000 \
  --restart no \
  pdf-editor:latest
```

## 🛠️ 手动配置（如果自动配置失败）

### 步骤1：确保Docker服务开机自启

```bash
# 启用Docker服务
sudo systemctl enable docker

# 验证
systemctl is-enabled docker
```

### 步骤2：更新容器重启策略

如果容器已存在，更新重启策略：

```bash
docker update --restart unless-stopped pdf-editor
```

### 步骤3：验证配置

```bash
# 查看容器详细信息
docker inspect pdf-editor | grep -A 5 RestartPolicy
```

## 📋 开机启动流程

```
系统启动
    ↓
systemd 启动 Docker 服务
    ↓
Docker 检查所有容器的重启策略
    ↓
找到 pdf-editor 容器 (restart: unless-stopped)
    ↓
自动启动 pdf-editor 容器
    ↓
Flask 应用启动，监听 5000 端口
    ↓
✅ 服务可用
```

**启动时间：** 通常在系统启动后 30-60 秒内完成

## 🔍 故障排除

### 问题1：系统重启后容器没有自动启动

**检查步骤：**

```bash
# 1. 检查Docker服务是否运行
systemctl status docker

# 2. 如果未运行，启动它
sudo systemctl start docker
sudo systemctl enable docker

# 3. 手动启动容器
docker start pdf-editor

# 4. 检查容器日志
docker logs pdf-editor
```

### 问题2：容器启动但应用无法访问

**检查步骤：**

```bash
# 1. 检查容器状态
docker ps -a | grep pdf-editor

# 2. 查看详细日志
docker logs --tail 100 pdf-editor

# 3. 检查端口映射
docker port pdf-editor

# 4. 测试端口
curl http://localhost:5000
```

### 问题3：Docker服务未设置开机自启

**解决方法：**

```bash
# 统信UOS / Debian系
sudo systemctl enable docker
sudo systemctl start docker

# 验证
systemctl is-enabled docker
```

### 问题4：容器重启策略不正确

**解决方法：**

```bash
# 查看当前策略
docker inspect --format='{{.HostConfig.RestartPolicy.Name}}' pdf-editor

# 更新策略
docker update --restart unless-stopped pdf-editor

# 或者重新创建容器
docker stop pdf-editor
docker rm pdf-editor
# 然后重新运行部署脚本
```

## 🔐 权限问题

### 普通用户运行Docker

如果希望不使用 `sudo` 运行Docker命令：

```bash
# 1. 将用户添加到docker组
sudo usermod -aG docker $USER

# 2. 重新登录或执行
newgrp docker

# 3. 测试
docker ps
```

**注意：** 这会给予用户相当于root的权限，请谨慎使用。
