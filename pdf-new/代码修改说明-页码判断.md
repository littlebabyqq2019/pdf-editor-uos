# 代码修改说明 - 增加页码判断逻辑

## 修改时间
2024年12月8日

## 修改文件
`pdf-new/pdf_processor.py`

## 修改目的
解决1.pdf第4页公章无法删除的问题。原因是代码在所有页面都使用相同的"红头保护"逻辑，导致非首页的公章也被错误判定为红头区域而被跳过。

## 修改内容

### 1. 增加页码获取（第861-863行）

```python
# 获取当前页面的页码（从0开始）
page_num = page.number
print(f"[DEBUG] 当前页面页码: {page_num + 1}")
```

### 2. 增加首页判断标志（第894-898行）

```python
# 定义页面上部区域（红头文字区域）
# 红头只会出现在首页，非首页不需要保护红头区域
# PDF坐标系：y=0在底部，y=page_height在顶部
# 首页上部区域：y > page_height * 0.4（距底部大于40%）
upper_area_y_threshold = page_height * 0.4
is_first_page = (page_num == 0)
```

### 3. 修改位置判定逻辑（第926-936行）

**修改前：**
```python
# 判断是否在上部（红头区域）
if y_center > upper_area_y_threshold:
    in_upper_area = True
    print(f"[DEBUG] 注释xref={xref}在页面上部...")
else:
    in_middle_or_bottom = True
    print(f"[DEBUG] 注释xref={xref}在页面中下部...")
```

**修改后：**
```python
# 判断是否在上部（红头区域）
# 红头只在首页存在，非首页的所有注释都可以删除
if is_first_page and y_center > upper_area_y_threshold:
    in_upper_area = True
    print(f"[DEBUG] 注释xref={xref}在首页上部（y中心={y_center:.1f}, 距顶部={from_top:.1f}），跳过")
else:
    in_middle_or_bottom = True
    if is_first_page:
        print(f"[DEBUG] 注释xref={xref}在首页中下部（y中心={y_center:.1f}, 距底部={from_bottom:.1f}）")
    else:
        print(f"[DEBUG] 注释xref={xref}在第{page_num+1}页（y中心={y_center:.1f}），非首页直接可删除")
```

### 4. 修改外观流清除时的判定逻辑（第971-977行）

**修改前：**
```python
# 如果是中下部的签名字段
if (is_signature or (is_widget and has_stamp_keyword)) and y_center <= upper_area_y_threshold:
    print(f"[DEBUG] 清除签名字段 xref={xref} 的外观流")
```

**修改后：**
```python
# 如果是签名字段（首页需要判断位置，非首页直接处理）
if (is_signature or (is_widget and has_stamp_keyword)) and (not is_first_page or y_center <= upper_area_y_threshold):
    if not is_first_page:
        print(f"[DEBUG] 第{page_num+1}页的签名字段 xref={xref}，非首页直接删除")
    else:
        print(f"[DEBUG] 首页中下部的签名字段 xref={xref}")
    print(f"[DEBUG] 清除签名字段 xref={xref} 的外观流")
```

## 修改逻辑说明

### 修改前的问题
所有页面（包括非首页）都使用40%阈值判定：
- y中心 > 40%页高 → 判定为"上部区域"，跳过删除
- y中心 ≤ 40%页高 → 判定为"中下部"，可以删除

这导致第4页y中心=628.7(74.7%)的公章被错误地判定为"上部区域"。

### 修改后的逻辑

| 页面类型 | 判定逻辑 | 结果 |
|---------|---------|------|
| **首页 (page_num=0)** | 使用40%阈值判定<br>- y > 40% → 上部（红头区域），跳过<br>- y ≤ 40% → 中下部，可删除 | 保护红头，删除中下部公章 |
| **非首页 (page_num>0)** | 不判定位置<br>直接 `in_middle_or_bottom = True` | 删除所有公章（无红头保护） |

### 为什么这样修改是正确的

1. **红头只在首页**
   - 红头文字、红头图案只会出现在文档的首页
   - 非首页不会有红头

2. **公章分布规律**
   - 首页：通常在中下部（红头下方的正文区域）
   - 非首页：可以出现在任何位置

3. **对1.pdf的影响**
   - 第4页公章（y=628.7）
   - 修改前：628.7 > 336.76 → "上部区域" → 跳过 ❌
   - 修改后：非首页 → 直接可删除 → 删除 ✅
