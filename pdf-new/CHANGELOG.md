# 更新日志

## [修复] 2024-11-28 - WPS公章显示问题修复

### 🐛 问题描述
文本型PDF文件经过"去红头及公章"处理后，在WPS手机版和WPS电脑版中公章仍然可见。

### 🔍 根本原因
- 旧代码只删除了页面的`/Annots`引用
- 签名字段对象及其外观流（`/AP`）仍保留在PDF中
- WPS会扫描全文档并渲染所有包含`/AP`的签名字段，即使它们未被引用

### ✅ 修复内容

#### 修改的文件
- **`pdf_processor.py`** - 主要修复

#### 修改的方法
- `_remove_annots_from_page_object()` - 增强签名字段删除逻辑

#### 新增逻辑
1. **清空外观流对象**
   - 提取`/AP/N`引用的外观流对象xref
   - 将外观流对象内容替换为空流

2. **重构签名字段对象**
   - 只保留必要的键（`/T`, `/F`, `/Rect`, `/P`）
   - 移除`/AP`、`/V`、`/DR`键

3. **增强垃圾回收**
   - 确保使用`garbage=4, deflate=True, clean=True`参数保存

### 📊 修复效果

#### 修复前
```
签名字段对象: 存在
/AP外观流: 存在
WPS显示: ❌ 公章可见
```

#### 修复后
```
签名字段对象: 不存在
/AP外观流: 已清空
WPS显示: ✅ 公章不可见（预期）
```

### 🔧 技术细节

#### 修改前的代码逻辑
```python
# 只删除/Annots引用
doc.xref_set_key(page_xref, "Annots", "null")
```

#### 修改后的代码逻辑
```python
# 1. 清空外观流对象
ap_xref = 提取/AP/N引用
doc.update_object(ap_xref, "<< /Length 0 >>\nstream\n\nendstream")

# 2. 重构签名字段对象
new_obj = 构建不含/AP的新对象
doc.update_object(xref, new_obj)

# 3. 删除/Annots引用
doc.xref_set_key(page_xref, "Annots", "null")

# 4. 垃圾回收
doc.save(output_path, garbage=4, deflate=True, clean=True)
```

### ⚠️ 注意事项

1. **位置判断**：只删除页面中下部的签名字段（距底部<500）
2. **上部保护**：页面上部的红头区域不受影响
3. **兼容性**：修复后的PDF在所有阅读器中都能正常打开
4. **WPS特性**：WPS的渲染机制与标准PDF阅读器不同
