========================================
🔧 手动部署（如果脚本失败）
========================================

如果自动脚本有问题，可以手动执行：

# 1. 清理旧部署
sudo docker stop pdf-editor 2>/dev/null
sudo docker rm pdf-editor 2>/dev/null
sudo docker rmi pdf-editor:latest 2>/dev/null

# 2. 加载ARM64镜像
sudo docker load -i pdf-editor-image-arm64.tar

# 3. 验证架构
sudo docker inspect pdf-editor:arm64 | grep Architecture
# 应该显示: "Architecture": "arm64"

# 4. 配置Docker开机自启
sudo systemctl enable docker
sudo systemctl start docker

# 5. 运行容器
sudo docker run -d \
  --name pdf-editor \
  -p 5000:5000 \
  -v ~/pdf-editor/processed:/app/processed \
  -e TZ=Asia/Shanghai \
  --restart unless-stopped \
  pdf-editor:arm64

# 6. 检查状态
sudo docker ps | grep pdf-editor
sudo docker logs pdf-editor

# 7. 测试访问
curl http://localhost:5000

🔧 故障排除
========================================

【如果容器无法启动】
1. 查看详细日志
   sudo docker logs pdf-editor

2. 检查架构匹配
   uname -m  # 应显示 aarch64
   sudo docker inspect pdf-editor:arm64 | grep Architecture

3. 检查端口占用
   netstat -tunlp | grep 5000

【如果无法访问】
1. 检查容器状态
   sudo docker ps

2. 检查防火墙
   sudo ufw status
   sudo ufw allow 5000/tcp

3. 测试本地访问
   curl -v http://localhost:5000
