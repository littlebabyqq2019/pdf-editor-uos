## 更新内容

### 🔧 核心修复

#### 1. 增加页码判断逻辑（文本型PDF）
**问题描述**：
- v1.5.0版本在处理文本型PDF时，所有页面都使用相同的"红头保护"逻辑
- 导致非首页的公章也被错误判定为红头区域而被跳过删除
- 例如：1.pdf第4页的公章（y=628.7）无法删除

**修复方案**：
- 增加页码判断，区分首页和非首页
- **首页**：保护上部区域（红头），只删除中下部公章
- **非首页**：不保护任何区域，删除所有公章

**修改文件**：
- `pdf_processor.py` - `_remove_annots_from_page_object()` 方法

**代码变更**：
```python
# 获取当前页面的页码（从0开始）
page_num = page.number
is_first_page = (page_num == 0)

# 判断逻辑
if is_first_page and y_center > upper_area_y_threshold:
    in_upper_area = True  # 首页上部，保护
else:
    in_middle_or_bottom = True  # 首页中下部或非首页，删除
```

#### 2. 统一保护区域标准（文本型PDF）
**问题描述**：
- 文本型PDF使用40%保护区域
- 扫描型PDF使用63%保护区域
- 标准不一致

**修复方案**：
- 将文本型PDF的保护区域从40%改为63%
- 与扫描型PDF保持一致
- 更符合实际红头文字分布范围

**代码变更**：
```python
# 修改前
upper_area_y_threshold = page_height * 0.4  # 40%

# 修改后
upper_area_y_threshold = page_height * 0.63  # 63%
```

## 判定逻辑完整流程

### 文本型PDF

```
处理页面 page_num
  ↓
判断：是否首页？
  ├─ 是（page_num = 0）
  │   ↓
  │  判断：y中心 > 63%页高？
  │   ├─ 是 → 上部区域（红头） → 保留
  │   └─ 否 → 中下部 → 删除
  │
  └─ 否（page_num > 0）
      ↓
     直接删除（无保护）
```

### 扫描型PDF

```
处理页面 page_num
  ↓
判断：是否首页？
  ├─ 是 → 保护上部63%（红头）
  └─ 否 → 全页检测删除
```

## 统一标准

| PDF类型 | 首页保护区域 | 非首页 |
|---------|-------------|--------|
| **文本型PDF** | 上部63% | 无保护，删除所有 |
| **扫描型PDF** | 上部63% | 无保护，删除所有 |

✅ **完全统一**
