🔄 开机自启详解
========================================

【自动配置内容】
✓ Docker服务设置为开机自启
  命令: systemctl enable docker
  
✓ 容器配置自动重启策略
  参数: --restart unless-stopped
  
✓ 系统重启后自动运行
  流程: 系统启动 → Docker启动 → 容器启动 → 应用可用

【启动时间】
约30-60秒（从系统启动到应用可用）

【验证方法】
# 重启系统
sudo reboot

# 等待1分钟后检查
docker ps | grep pdf-editor

# 访问应用
curl http://localhost:5000

【重启策略说明】
unless-stopped 意味着：
  ✓ 系统重启 → 自动启动
  ✓ Docker重启 → 自动启动
  ✓ 容器崩溃 → 自动重启
  ✗ 手动停止 → 不会自动启动

========================================
🛠️ 故障排除
========================================

【问题1】容器未自动启动

解决:
1. 检查Docker服务
   sudo systemctl status docker
   sudo systemctl start docker

2. 手动启动容器
   docker start pdf-editor

3. 查看日志
   docker logs pdf-editor

【问题2】无法访问应用

解决:
1. 检查容器状态
   docker ps | grep pdf-editor

2. 检查端口
   docker port pdf-editor
   netstat -tunlp | grep 5000

3. 测试连接
   curl http://localhost:5000

【问题3】重启后不自动启动

解决:
1. 重新配置
   sudo systemctl enable docker
   docker update --restart unless-stopped pdf-editor

2. 验证配置
   systemctl is-enabled docker
   docker inspect pdf-editor | grep -A 5 RestartPolicy
