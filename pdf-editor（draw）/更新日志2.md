### 4. PDF文件名优化（中文支持）✅

**修改前**：
- 下载文件名格式：`edited_pdf_20251124_220530.pdf`
- 无法保留原文件名
- 不便于识别

**修改后**：
- ✅ 在原文件名前添加"去红头-"前缀
- ✅ 完整支持中文文件名
- ✅ 保留原始文件信息

**示例**：
```
原文件名：项目报告.pdf
下载文件名：去红头-项目报告.pdf

原文件名：Document2024.pdf
下载文件名：去红头-Document2024.pdf
```

**实现方式**：
- 修改`generateFileName()`函数
- 从`AppState.pdfFile.name`获取原始文件名
- 添加"去红头-"前缀
- 文件：`static/js/pdfGenerator.js`

**代码**：
```javascript
function generateFileName() {
    let originalName = 'document.pdf';
    if (AppState.pdfFile && AppState.pdfFile.name) {
        originalName = AppState.pdfFile.name;
    }
    return '去红头-' + originalName;
}
```

### 6. 滚动切换页面功能 ✅

**新增功能**：
- ✅ 向下滚动到页面底部，自动切换到下一页
- ✅ 向上滚动到页面顶部，自动切换到上一页
- ✅ 防抖处理，避免频繁切换
- ✅ 平滑的页面切换体验

**工作原理**：
1. 监听`canvasContainer`的滚动事件
2. 检测滚动位置：
   - 距底部≤10px → 切换到下一页
   - 距顶部≤10px → 切换到上一页
3. 切换后重置滚动位置
4. 使用防抖（150ms）避免连续触发

**实现方式**：
- 添加`initScrollPageSwitch()`函数
- 在渲染页面时初始化滚动监听
- 使用标志位防止切换中的重复触发
- 文件：`static/js/pdfHandler.js`

**关键代码**：
```javascript
let scrollTimeout = null;
let isScrollSwitching = false;

function initScrollPageSwitch() {
    const container = document.getElementById('canvasContainer');
    container.addEventListener('scroll', function(e) {
        clearTimeout(scrollTimeout);
        scrollTimeout = setTimeout(() => {
            // 滚动到底部
            if (scrollTop + clientHeight >= scrollHeight - 10) {
                switchToPage(currentPageIndex + 1);
            }
            // 滚动到顶部
            else if (scrollTop <= 10) {
                switchToPage(currentPageIndex - 1);
            }
        }, 150);
    });
}
```
