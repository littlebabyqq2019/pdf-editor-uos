# 内网环境部署说明

## 问题解决

已彻底解决政务内网环境下的CDN依赖问题，确保应用可以在完全离线的局域网环境中正常运行。

## 已完成的工作

### 1. 本地化所有第三方库

已将以下外部CDN资源下载到本地 `static/js` 目录：

- **Tailwind CSS** (tailwind.min.js) - 408KB
  - 原CDN: https://cdn.tailwindcss.com
  - 本地路径: /static/js/tailwind.min.js

- **PDF.js** (pdf.min.js + pdf.worker.min.js) - 1.4MB
  - 原CDN: https://cdnjs.cloudflare.com/ajax/libs/pdf.js/3.11.174/
  - 本地路径: /static/js/pdf.min.js, /static/js/pdf.worker.min.js

- **Fabric.js** (fabric.min.js) - 312KB
  - 原CDN: https://cdnjs.cloudflare.com/ajax/libs/fabric.js/5.3.0/
  - 本地路径: /static/js/fabric.min.js

- **jsPDF** (jspdf.umd.min.js) - 364KB
  - 原CDN: https://cdnjs.cloudflare.com/ajax/libs/jspdf/2.5.1/
  - 本地路径: /static/js/jspdf.umd.min.js

- **Sortable.js** (Sortable.min.js) - 44KB
  - 原CDN: https://cdnjs.cloudflare.com/ajax/libs/Sortable/1.15.0/
  - 本地路径: /static/js/Sortable.min.js

### 2. 更新文件引用

已更新以下文件中的资源引用：

- **templates/index.html**: 所有5个CDN引用已替换为本地路径
- **static/js/pdfHandler.js**: PDF.js worker路径已更新为本地路径

### 3. 验证结果

✅ 所有外部CDN依赖已移除
✅ 所有资源文件已本地化
✅ 应用可在无互联网连接的环境中运行
✅ 无需访问任何外部网络资源

## 部署步骤

在政务内网或局域网环境部署时：

1. **确保所有文件完整**: 
   - 检查 `static/js` 目录包含所有第三方库文件
   - 确认文件大小正常（总计约2.5MB）

2. **启动应用**:
   ```bash
   python app.py
   ```
   或使用打包的可执行文件

3. **访问应用**:
   - 浏览器访问: http://localhost:5000
   - 或配置的其他端口

## 技术说明

- 应用现在是**完全自包含**的，不依赖任何外部网络资源
- 所有JavaScript库都从本地Flask服务器加载
- CSS样式通过Tailwind CSS本地版本生成
- PDF渲染完全在本地处理

## 测试建议

为确保在内网环境正常运行，建议：

1. 断开互联网连接后测试
2. 在纯局域网环境中测试
3. 检查浏览器控制台无网络错误
4. 验证所有功能正常：
   - PDF上传和显示
   - 文字编辑
   - 图形绘制
   - PDF导出

## 注意事项

- 确保Flask服务器的静态文件路由正常工作
- 如需更新第三方库版本，重新下载后替换对应文件即可
- 打包部署时确保 `static/js` 目录包含在内
