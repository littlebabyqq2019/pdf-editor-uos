### 1. 修复滚动切换页面跳动问题 ✅

#### 问题描述
- 使用鼠标滚轮切换页面时
- 页面会在两个页面之间反复跳动
- 无法稳定停留在目标页面

#### 根本原因
1. **延迟不足**：重置滚动位置后立即解锁，导致新的滚动事件触发
2. **滚动阈值过大**：10px的阈值容易误触发
3. **防抖时间过短**：150ms不足以避免连续触发

#### 解决方案

**改进1：增加防抖时间**
```javascript
// 之前：150ms
scrollTimeout = setTimeout(() => { ... }, 150);

// 现在：200ms
scrollTimeout = setTimeout(() => { ... }, 200);
```

**改进2：减小滚动阈值**
```javascript
// 之前：距离边缘10px触发
if (scrollTop + clientHeight >= scrollHeight - 10)

// 现在：距离边缘5px触发（更精准）
if (scrollTop + clientHeight >= scrollHeight - 5)
```

**改进3：延迟解锁标志位**
```javascript
switchToPage(nextPage).then(() => {
    setTimeout(() => {
        container.scrollTop = 0;
        // 再延迟200ms解锁
        setTimeout(() => {
            isScrollSwitching = false;
        }, 200);
    }, 150);
});
```

**改进4：双重检查标志位**
```javascript
scrollTimeout = setTimeout(() => {
    // 再次检查标志位，避免延迟期间状态变化
    if (isScrollSwitching) return;
    // ... 处理逻辑
}, 200);
```

#### 效果
- ✅ 页面切换平滑，不再跳动
- ✅ 可以稳定停留在目标页面
- ✅ 向上/向下滚动都正常工作

### 2. 修复撤销重做功能问题 ✅

#### 问题描述

**撤销按钮问题**：
- 有些操作撤销不掉
- 撤销后再添加新对象，历史记录混乱

**重做按钮问题**：
- 点击重做按钮完全不起作用
- 撤销后无法重做

#### 根本原因

**原因1：事件冲突**
- `object:added` 事件在任何对象添加时都会触发
- 包括手动添加、撤销/重做恢复、页面切换恢复
- 导致历史记录重复保存和混乱

**原因2：重做失效**
- 撤销后添加新对象时没有正确清理后续历史
- 但实际上代码是对的，问题在于事件触发时机

**原因3：撤销/重做时触发保存**
- 撤销/重做时加载JSON会触发 `object:added` 事件
- 导致刚撤销的状态又被保存回去
- 形成死循环

#### 解决方案

**解决方案1：添加标志位防止循环保存**

在 `AppState` 中添加 `isUndoRedoing` 标志：
```javascript
const AppState = {
    // ... 其他属性
    isUndoRedoing: false  // 标志：是否正在执行撤销/重做
};
```

**解决方案2：在撤销/重做时设置标志**
```javascript
function undo() {
    if (AppState.historyStep > 0) {
        AppState.isUndoRedoing = true;  // 设置标志
        AppState.historyStep--;
        AppState.fabricCanvas.loadFromJSON(state, () => {
            AppState.fabricCanvas.renderAll();
            // 延迟解除标志，确保所有事件处理完成
            setTimeout(() => {
                AppState.isUndoRedoing = false;
            }, 100);
        });
    }
}

function redo() {
    if (AppState.historyStep < AppState.canvasHistory.length - 1) {
        AppState.isUndoRedoing = true;  // 设置标志
        AppState.historyStep++;
        // ... 同样的逻辑
    }
}
```

**解决方案3：保存时检查标志**
```javascript
function saveCanvasState() {
    if (!AppState.fabricCanvas) return;
    
    // 如果正在执行撤销/重做，不保存状态
    if (AppState.isUndoRedoing) return;
    
    // ... 保存逻辑
}
```

**解决方案4：移除object:added事件监听**
```javascript
// 之前：监听object:added
AppState.fabricCanvas.on('object:added', () => {
    saveCanvasState();  // 会导致重复保存
});

// 现在：不监听object:added
// 因为手动添加对象时editor.js已经调用了saveCanvasState()
```

**解决方案5：页面切换时也设置标志**
```javascript
// 恢复该页面的编辑数据
if (AppState.pages[index].fabricData) {
    AppState.isUndoRedoing = true;  // 防止触发保存
    AppState.fabricCanvas.loadFromJSON(data, () => {
        AppState.fabricCanvas.renderAll();
        setTimeout(() => {
            AppState.isUndoRedoing = false;
        }, 100);
    });
}
```

#### 工作流程

**正常添加对象**：
1. 用户添加文字/形状/等
2. editor.js 调用 `saveCanvasState()`
3. 检查 `isUndoRedoing = false`，保存成功 ✅
4. 历史记录正确更新

**撤销操作**：
1. 用户点击撤销按钮
2. 设置 `isUndoRedoing = true`
3. 加载历史状态，触发 `object:added` 等事件
4. `saveCanvasState()` 被调用，但检查到标志，直接返回 ✅
5. 100ms后解除标志
6. 不会保存撤销的中间状态

**重做操作**：
1. 用户点击重做按钮
2. 设置 `isUndoRedoing = true`
3. 向前移动历史指针
4. 加载状态，同样不会触发保存 ✅
5. 重做成功

**添加新对象后重做失效**（预期行为）：
1. 撤销几步
2. 添加新对象
3. `saveCanvasState()` 正确清理后续历史：
   ```javascript
   AppState.canvasHistory = AppState.canvasHistory.slice(0, AppState.historyStep + 1);
   ```
4. 重做按钮正确变为不可用 ✅

#### 效果
- ✅ 撤销功能正常，所有操作都能撤销
- ✅ 重做功能正常，可以重做已撤销的操作
- ✅ 撤销后添加新内容，后续历史正确清除
- ✅ 不会出现历史记录混乱
- ✅ 切换页面时不影响历史记录

## 技术细节

### 滚动切换优化

**时间控制**：
- 防抖时间：150ms → 200ms
- 切换后延迟：150ms
- 解锁延迟：200ms
- 总锁定时间：~350ms（确保切换完成）

**阈值调整**：
- 触发距离：10px → 5px
- 更精准，减少误触发

**标志位管理**：
```
触发切换 → 设置 isScrollSwitching = true
         ↓
    切换页面 (async)
         ↓
    延迟150ms
         ↓
    重置滚动位置
         ↓
    延迟200ms
         ↓
    解锁 isScrollSwitching = false
```

### 撤销重做优化

**状态保存控制流**：
```
操作发生 → saveCanvasState() 调用
         ↓
    检查 isUndoRedoing?
         ↓
    false → 正常保存
    true  → 直接返回（不保存）
```

**历史记录管理**：
```
初始: []
添加对象A: [A]  historyStep=0
添加对象B: [A, B]  historyStep=1
撤销: historyStep=0
添加对象C: [A, C]  historyStep=1  (B被清除)
```

**事件监听优化**：
```
之前:
- object:modified → saveCanvasState()
- object:added → saveCanvasState()  ❌ 会重复保存

现在:
- object:modified → saveCanvasState()
- object:added → 不监听  ✅ 手动添加时已调用
```

## 问题解决总结

### 滚动跳动
- **原因**：时序问题，重置滚动位置触发新事件
- **解决**：延长锁定时间，增加防抖，双重检查

### 撤销失效
- **原因**：event:added重复触发，历史记录混乱
- **解决**：添加标志位，移除冗余监听

### 重做失效
- **原因**：撤销/重做时误保存状态
- **解决**：在撤销/重做时阻止保存
