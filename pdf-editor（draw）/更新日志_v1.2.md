## ✨ 主要更新

### 🐛 Bug修复：混合页面方向问题（重要）

#### 问题描述
- **问题**：处理包含横竖混合方向的PDF时，横版页面保存后被强制转为竖版
- **影响**：横版页面内容被压缩变形或右侧被裁剪
- **场景**：政务文件（封面竖版+附表横版）、报告文档等

#### 修复内容
1. ✅ **完善页面尺寸处理**
   - 为每页单独获取原始尺寸
   - 不再强制所有页面使用第一页尺寸

2. ✅ **添加方向参数**
   - 根据宽高比自动判断页面方向（landscape/portrait）
   - 为每页添加明确的orientation参数
   - 确保横版页面保持横版布局

3. ✅ **第一页特殊处理**
   - 处理第一页方向不匹配的情况
   - 确保整个PDF的方向一致性

#### 技术细节
```javascript
// 为每页计算尺寸和方向
const page = await AppState.pdfDoc.getPage(AppState.pages[i].pageNumber);
const viewport = page.getViewport({ scale: 1.5 });
const pageWidth = viewport.width * 0.264583;
const pageHeight = viewport.height * 0.264583;
const orientation = pageWidth > pageHeight ? 'landscape' : 'portrait';

// 添加页面时指定方向
pdf.addPage([pageWidth, pageHeight], orientation);
pdf.addImage(pageImage, 'PNG', 0, 0, pageWidth, pageHeight);
```

#### 修复效果
- ✅ 横版页面保持横版布局，不被压缩
- ✅ 竖版页面保持竖版布局
- ✅ 右侧内容不被裁剪
- ✅ 所有文字完整可见，无变形
- ✅ 支持任意组合的混合方向PDF
