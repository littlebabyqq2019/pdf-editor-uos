## 🛠️ 技术栈

### 后端
- **Python 3.8+**
- **Flask 2.3.0** - Web框架

### 前端
- **HTML5 + CSS3** - 页面结构和样式
- **JavaScript (ES6+)** - 核心逻辑
- **TailwindCSS 3.x** - UI框架
- **PDF.js 3.11** - PDF渲染库
- **Fabric.js 5.3** - Canvas编辑库
- **jsPDF 2.5** - PDF生成库
- **Sortable.js 1.15** - 拖拽排序库

## 🚀 运行方式

### 方法一：使用启动脚本（推荐）
1. 双击 `start.bat`
2. 等待自动配置环境和安装依赖
3. 浏览器访问显示的地址

### 方法二：手动运行
```bash
# 1. 创建虚拟环境
python -m venv venv

# 2. 激活虚拟环境
venv\Scripts\activate  # Windows
source venv/bin/activate  # Linux/Mac

# 3. 安装依赖
pip install -r requirements.txt

# 4. 运行应用
python app.py
```

### 访问地址
- 本机: http://localhost:5000
- 局域网: http://[你的IP]:5000

## 💡 使用建议

1. **浏览器选择**：推荐使用Chrome、Firefox、Edge等现代浏览器
2. **文件大小**：建议单个PDF不超过50MB，页数不超过100页
3. **编辑习惯**：定期保存（Ctrl+S），避免意外丢失
4. **网络环境**：v1.1+版本支持完全离线运行，无需网络连接（内网环境友好）
5. **性能优化**：处理大文件时，建议关闭其他浏览器标签页

## 🔧 Bug修复记录

### v1.2 (2025-11-26)
- ✅ **修复**：混合页面方向问题
  - 问题：横版页面保存后被压缩变形
  - 原因：所有页面强制使用第一页尺寸
  - 解决：为每页单独保持原始尺寸和方向
  - 影响文件：`static/js/pdfGenerator.js`
  - 详细说明：见 `bug修复_混合页面方向.md`

### v1.1 (2025-11-25)
- ✅ **修复**：CDN依赖问题
  - 问题：政务内网环境无法加载CDN资源
  - 解决：所有第三方库本地化
  - 影响文件：`templates/index.html`, `static/js/pdfHandler.js`
  - 新增资源：约2.5MB的JavaScript库文件

## 🐛 已知限制

1. PDF中的交互元素（表单、注释）可能无法完美保留
2. 复杂的PDF特效可能渲染有差异
3. 非常大的PDF文件（>100MB）可能导致浏览器卡顿
4. 不支持编辑加密的PDF文件
