#### 1.2 单次插入限制

**修改前**：
- 点击文字按钮后
- 每次在页面点击都会插入新文本框
- 容易误操作创建多个文本框

**修改后**：
- ✅ 点击文字按钮后
- ✅ **只能插入一个文本框**
- ✅ 插入后再点击页面不会创建新文本框
- ✅ 需要再次点击文字按钮才能插入下一个

**实现机制**：
```javascript
// 添加标记变量
let textInserted = false;

function setupTextMode() {
    textInserted = false; // 重置标记
    
    canvas.on('mouse:down', function(options) {
        // 如果已插入，不再创建
        if (textInserted) return;
        
        // 创建文本框...
        textInserted = true; // 标记已插入
    });
}
```

**优势**：
- 防止误操作
- 更精准的文字添加
- 符合常见编辑器习惯

## 代码改动详解

### 1. 文字工具改动（editor.js）

**关键改动**：

```javascript
// 添加状态标记
let textInserted = false;

function setupTextMode() {
    textInserted = false; // 每次切换到文字模式时重置
    
    canvas.on('mouse:down', function(options) {
        // 1. 检查是否已插入
        if (textInserted) return;
        
        // 2. 检查是否点击在已有对象上
        if (options.target) return;
        
        // 3. 创建空白文本框（不是预填文字）
        const text = new fabric.IText('', {
            left: pointer.x,
            top: pointer.y,
            // ... 其他属性
        });
        
        // 4. 添加到画布并进入编辑模式
        canvas.add(text);
        canvas.setActiveObject(text);
        text.enterEditing(); // 自动进入编辑
        
        // 5. 标记已插入
        textInserted = true;
    });
}
```

**行为说明**：
1. 点击"文字"按钮 → `textInserted = false`（重置）
2. 在页面点击 → 创建空白文本框 → `textInserted = true`
3. 再点击页面 → `textInserted = true`，不创建新文本框
4. 再次点击"文字"按钮 → `textInserted = false`（重置） → 可以插入新文本框

## 技术细节

### 文字工具状态管理

使用模块级变量 `textInserted` 来跟踪插入状态：

- **作用域**：editor.js 模块
- **生命周期**：页面加载后持续存在
- **重置时机**：每次调用 `setupTextMode()` 时

### 事件监听器管理

每次切换工具时，Fabric.js 会：
1. 清除所有旧的事件监听器
2. 设置新的事件监听器

这确保了工具切换的正确性。
