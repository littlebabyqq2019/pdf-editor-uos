## 更新内容

### 编辑区域缩放功能 ✅

#### 功能概述
添加了编辑区域的缩放功能，用户可以自由放大或缩小PDF编辑区域，便于精细编辑或查看全局。

**特点**：
- ✅ 只缩放编辑区域（画布+标尺）
- ✅ 不影响其他UI组件
- ✅ 支持多级缩放
- ✅ 平滑过渡动画
- ✅ 键盘快捷键支持

---

## 功能详情

### 1. 缩放控件

**位置**：工具栏右侧，删除按钮和保存按钮之间

**组件**：
- 🔍 **缩小按钮**：减小缩放比例
- 📊 **缩放显示**：显示当前缩放百分比
- 🔎 **放大按钮**：增加缩放比例  
- 🔄 **重置按钮**：恢复到100%

---

### 2. 缩放级别

**支持的缩放级别**：
```
25%  →  50%  →  75%  →  100%  →  125%  →  150%  →  200%  →  300%  →  400%
```

**默认级别**：100%（原始大小）

**级别切换**：
- 每次点击按钮，按数组顺序切换
- 达到最大/最小值时，按钮自动禁用
- 可通过快捷键快速切换

---

### 3. 快捷键

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 放大 | `Ctrl` + `+` | 增加一级缩放 |
| 缩小 | `Ctrl` + `-` | 减小一级缩放 |
| 重置 | `Ctrl` + `0` | 恢复100% |
| 撤销 | `Ctrl` + `Z` | 撤销操作 |
| 重做 | `Ctrl` + `Y` | 重做操作 |

---

### 4. 视觉效果

**过渡动画**：
```css
transition: transform 0.3s ease;
```
- 持续时间：0.3秒
- 缓动函数：ease
- 平滑自然的缩放体验

**缩放原点**：
```css
transform-origin: top center;
```
- 从顶部中心缩放
- 保持编辑区域水平居中
- 缩放时不跳动

### JavaScript实现

**缩放级别数组**：
```javascript
const zoomLevels = [0.25, 0.5, 0.75, 1, 1.25, 1.5, 2, 3, 4];
let currentZoomIndex = 3; // 默认100%
```

**应用缩放**：
```javascript
function applyZoom() {
    const zoom = zoomLevels[currentZoomIndex];
    AppState.zoom = zoom;
    
    // 应用CSS变换
    const editorWrapper = document.getElementById('editorWrapper');
    editorWrapper.style.transform = `scale(${zoom})`;
    editorWrapper.style.transformOrigin = 'top center';
    
    // 更新显示
    document.getElementById('zoomDisplay').textContent = `${Math.round(zoom * 100)}%`;
}
```

**放大函数**：
```javascript
function zoomIn() {
    if (currentZoomIndex < zoomLevels.length - 1) {
        currentZoomIndex++;
        applyZoom();
    }
}
```

**缩小函数**：
```javascript
function zoomOut() {
    if (currentZoomIndex > 0) {
        currentZoomIndex--;
        applyZoom();
    }
}
```

**重置函数**：
```javascript
function zoomReset() {
    currentZoomIndex = 3; // 100%
    applyZoom();
}
```

### 键盘事件

**快捷键监听**：
```javascript
document.addEventListener('keydown', function(e) {
    // Ctrl+加号 放大
    if (e.ctrlKey && (e.key === '+' || e.key === '=')) {
        e.preventDefault();
        zoomIn();
    }
    
    // Ctrl+减号 缩小
    if (e.ctrlKey && e.key === '-') {
        e.preventDefault();
        zoomOut();
    }
    
    // Ctrl+0 重置
    if (e.ctrlKey && e.key === '0') {
        e.preventDefault();
        zoomReset();
    }
});
```

### 当前限制

1. **缩放范围**：25% - 400%

2. **标尺缩放**：标尺跟随缩放

## 常见问题

### Q: 缩放后如何恢复？
A: 点击重置按钮或按 Ctrl+0

### Q: 缩放会影响导出吗？
A: 不会，缩放只是视图显示，不影响实际PDF

### Q: 最大能放大多少？
A: 400%（4倍）

### Q: 最小能缩小多少？
A: 25%（1/4）

### Q: 缩放后标尺不准？
A: 标尺会跟随缩放，实际尺寸不变
