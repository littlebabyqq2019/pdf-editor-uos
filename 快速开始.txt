一、安装步骤
───────────────────────────────────────────────────────────
1. 确保已安装 Python 3.8 或更高版本
   - 检查方法：打开命令提示符，输入 python --version
   - 如未安装，请访问 https://www.python.org/downloads/

2. 安装依赖包
   方法一（推荐）：
   - 双击运行 run.bat 文件，会自动安装依赖并启动

   方法二：
   - 打开命令提示符
   - 进入项目目录：cd "e:\dev\pdf-editor(2in1)"
   - 运行：pip install -r requirements.txt


二、启动应用
───────────────────────────────────────────────────────────
方法一（推荐）：
  双击运行 run.bat 文件

方法二：
  1. 打开命令提示符
  2. 进入项目目录：cd "e:\dev\pdf-editor(2in1)"
  3. 运行：python app.py


三、访问应用
───────────────────────────────────────────────────────────
启动成功后，您将看到访问地址：

📍 本机访问:
   http://localhost:5000

🌐 局域网访问（其他设备访问）:
   http://192.168.x.x:5000
   （x.x 是您的实际IP地址，启动时会显示）


四、功能入口
───────────────────────────────────────────────────────────
1. PDF处理工具（主页）
   - 访问地址：http://IP:5000
   - 功能：去红头、去公章、PDF转换、合并拆分等

2. PDF编辑器
   - 访问方法：点击主页右上角的"PDF编辑器"按钮
   - 或直接访问：http://IP:5000/editor
   - 功能：在线编辑PDF、添加文字、绘图、标注等


五、使用流程
───────────────────────────────────────────────────────────
PDF处理工具：
  1. 拖拽或选择文件上传
  2. 选择需要的处理功能
  3. 等待处理完成
  4. 自动下载处理结果

PDF编辑器：
  1. 点击"PDF编辑器"进入编辑页面
  2. 上传PDF文件
  3. 使用工具栏编辑PDF
  4. 点击"保存并下载"获取编辑后的文件
  5. 点击"返回"按钮回到主页


六、注意事项
───────────────────────────────────────────────────────────
✓ 单个文件最大支持 100MB
✓ 支持的文件格式：PDF、JPG、PNG、BMP、TIFF
✓ 建议使用 Chrome、Edge 或 Firefox 浏览器
✓ 如遇到问题，可点击"终止并重启"按钮
✓ 局域网访问需确保防火墙允许 5000 端口


七、常见问题
───────────────────────────────────────────────────────────
Q: 启动失败怎么办？
A: 1. 检查Python是否正确安装
   2. 确认依赖包已正确安装
   3. 检查5000端口是否被占用

Q: 局域网其他设备无法访问？
A: 1. 检查防火墙设置
   2. 确认使用正确的IP地址
   3. 确保设备在同一局域网内

Q: 处理速度慢怎么办？
A: 1. 可尝试使用"多线程处理"选项
   2. 减小文件大小或分批处理
   3. 确保电脑性能充足

Q: 上传的文件去哪了？
A: 程序会自动管理临时文件，处理完成后会自动清理
