# PDF编辑工具集成版 v2.0

## 项目简介

这是一个整合了两个PDF应用的集成工具，包含：
- **PDF处理工具**（pdf-new）：提供PDF去红头、去公章、转换等功能
- **PDF编辑器**（pdf-editor draw）：提供PDF在线编辑、标注、绘图功能

## 功能特性

### 主页面 - PDF处理工具 (http://IP:5000)

1. **PDF处理功能**
   - 去红头及公章
   - 去公章
   - 转图片后去红头及公章
   - 转Word文档
   
2. **图片处理功能**
   - 去背景
   - 图片转PDF

3. **PDF页面管理**
   - 删除PDF页面（支持拖拽排序）
   - 合并多个PDF文件
   - 拆分PDF文件

### PDF编辑器页面 (http://IP:5000/editor)

1. **编辑工具**
   - 文字添加与编辑
   - 形状绘制（矩形、圆形、直线）
   - 擦除工具
   - 高亮显示
   - 下划线标注

2. **编辑功能**
   - 撤销/重做
   - 缩放控制
   - 页面预览
   - 保存并下载

## 安装说明

### 1. 环境要求
- Python 3.8+
- Windows操作系统

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 启动应用

```bash
python app.py
```

或在Windows上双击运行：
```bash
run.bat
```

## 使用说明

### 启动服务

运行应用后，您将看到：

```
============================================================
PDF编辑工具集成版 v2.0 已启动
============================================================
📍 本机访问: http://localhost:5000
🌐 局域网访问: http://192.168.x.x:5000
📄 PDF处理工具: http://192.168.x.x:5000
✏️  PDF编辑器: http://192.168.x.x:5000/editor
按 Ctrl+C 可停止服务
============================================================
```

### 访问应用

1. **主页面（PDF处理工具）**
   - 浏览器打开：`http://IP:5000`
   - 支持文件拖拽上传
   - 选择相应功能处理PDF文件

2. **PDF编辑器**
   - 点击主页右上角的"PDF编辑器"按钮
   - 或直接访问：`http://IP:5000/editor`
   - 上传PDF后即可进行编辑

### 页面导航

- **主页 → 编辑器**：点击主页右上角的"PDF编辑器"按钮
- **编辑器 → 主页**：点击编辑器左上角的"返回"按钮

## 技术栈

- **后端框架**：Flask 2.3.3
- **PDF处理**：PyMuPDF (fitz), PyPDF2
- **图像处理**：Pillow, OpenCV, scikit-image
- **文档转换**：python-docx, reportlab
- **前端**：HTML5, CSS3, JavaScript
- **UI框架**：TailwindCSS（编辑器）

## 注意事项

1. **文件大小限制**：单个文件最大支持100MB
2. **临时文件**：程序启动时会自动清理uploads文件夹
3. **会话管理**：每个用户会话有独立的文件空间
4. **网络访问**：确保防火墙允许5000端口访问
5. **浏览器支持**：建议使用Chrome、Edge或Firefox最新版本

## 端口配置

默认端口：5000

如需修改端口，请编辑 `app.py` 文件的最后部分：

```python
app.run(host='0.0.0.0', port=5000, debug=False, use_reloader=False, threaded=True)
```

## 常见问题

### Q: 如何在局域网中访问？
A: 启动程序后，会显示局域网IP地址，局域网内其他设备使用该IP:5000即可访问。

### Q: 处理失败怎么办？
A: 可以点击"终止并重启"按钮重启服务，或者检查文件格式是否正确。

### Q: 支持哪些文件格式？
A: PDF、JPG、PNG、BMP、TIFF等常见格式。

### Q: 编辑后的PDF如何保存？
A: 在编辑器中点击"保存并下载"按钮即可下载编辑后的PDF。
